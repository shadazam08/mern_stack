# Task - 2 Laundry Wallah / Laundry Mart

## Laundry Wallah / Laundry Mart

This is a responsive and user-friendly HTML webpage built as part of the web development tasks. It represents an online platform for a professional laundry and garment care service.

## Features

- **Header Section**: Welcoming heading displaying the brand name.
- **About Section**: Brief introduction detailing the laundry services and commitment to garment care.
- **Image Section**: Visual representation using an online laundry image.
- **Services Section**: Unordered list showcasing various services like Washing & Drying, Ironing & Folding, Dry Cleaning, etc.
- **Price List Section**: Clean HTML table displaying service rates (Washing & Drying and Ironing & Folding).
- **Book Now Section**: Interactive form with required input fields for Name, Email, and Phone number along with a submit button.
- **Footer Section**: Contact information and support email.

## Built With

- **HTML5**: Semantic elements and structural markup.

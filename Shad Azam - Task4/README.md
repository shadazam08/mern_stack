# Task - 4 CSS - Units, Box Models, Fonts

## CSS - Units, Box Models, Fonts

This project is an HTML and CSS webpage created to practice and demonstrate CSS viewport units, the CSS box model, font styling, and gradient backgrounds without using Flexbox, positioning properties, or overflow clipping.

## Features & Implementation

- **HTML Setup**: Structured a semantic HTML5 document with a proper title and linked external stylesheet (`style.css`).
- **Body Content**: Built a section containing an image wrapper `<div>` with an image inside and an interactive **"Click Me"** button directly below it.
- **Viewport Spacing & Layout**: Configured the main container with `25vw` equal spacing from the left and right and `10vh` spacing from the top and bottom.
- **Box Model & Scroll Prevention**: Used `box-sizing: border-box` and viewport units (`vh` and `vw`) so the entire layout fits within the viewport without triggering page scroll.
- **Button Styling**: Customised the button with a horizontal yellow-to-green gradient background, custom font properties, and clean border styling.
- **CSS Constraints Followed**: Built purely with standard block layout—no `display: flex`, no `overflow: hidden`, and no `position: relative` or `position: absolute`.

## Built With

- **HTML5**: Document structure and media/button elements.
- **CSS3**: Viewport units (`vw`, `vh`), Box Model (`box-sizing`), typography, and linear gradients.

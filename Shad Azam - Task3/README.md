# Task - 3 CSS Selectors

## CSS Selectors

This is an HTML and CSS webpage built as part of the web development assignments to practice and demonstrate the application of various CSS selectors, including element, class, ID, and compound selectors.

## Features & Implementation

- **External CSS Setup**: Connected `style.css` to `index.html` with custom background styling for the body.
- **Heading Class Selectors (**`.head`**)**: Created 3 different heading tags with the `.head` class, styled with a dark blue text color.
- **Heading ID Styling (**`#bglime`**)**: Applied a distinct background color and red text styling to the second heading.
- **Paragraph Element Selectors (**`p`**)**: Created 3 paragraphs styled with white text using direct tag selectors.
- **Paragraph ID & Custom Styling (**`#para`**)**: Clean HTML table displaying service rates (Washing & Drying and Ironing & Folding).
- **List Styling**: Implemented list items and styled specific target words (`like "here"`) using advanced CSS selectors without inline styles, IDs, or classes.

## Built With

- **HTML5**: Semantic document structure.
- **CSS3**: Stylesheet rules and CSS Selectors.
